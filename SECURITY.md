# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately via GitHub:
**Security** tab → **Report a vulnerability** ([direct link](https://github.com/sebastianmaute/vortex-nivalisnights/security/advisories/new)).

Include what you found, how to reproduce it, and the extension version (shown in Vortex's Extensions tab).
I'll acknowledge reports as soon as I can; this is a one-person hobby project, so please allow a few days.

## Scope

In scope: this extension's code — game discovery, the installers, and how it configures Vortex and BepInEx.

Out of scope (report to the respective project):

- Vortex itself — [Nexus-Mods/Vortex](https://github.com/Nexus-Mods/Vortex/security)
- BepInEx — [BepInEx/BepInEx](https://github.com/BepInEx/BepInEx)
- Individual mods — their authors on Nexus Mods
- Nivalis Nights — the game's developer

## Supported versions

Only the latest release on [Nexus Mods](https://www.nexusmods.com/site/mods/2413) receives fixes.
